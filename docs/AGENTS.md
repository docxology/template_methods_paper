# Documentation maintenance

Start with [the documentation index](README.md). The
[agent instructions](agent_instructions.md) describe the code, test, and
manuscript boundaries. Keep the [quickstart](quickstart.md),
[render guide](rendering_pipeline.md), and [output inventory](output_inventory.md)
aligned with the actual build.

The maintained source is in [`manuscript/`](manuscript/README.md).
Edit the source, regenerate its variables and figures, and verify the new
outputs in a fresh build. Keep generated snapshots separate. See the
[manuscript editing rules](manuscript/AGENTS.md) for tokens and labels.
